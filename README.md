# go-ai

오목 룰을 명시적으로 주입하지 않은 단순 에이전트들이 서로 대국하며,
유전자 알고리즘으로 세대가 지날수록 전략이 바뀌는 과정을 시각화한 웹 앱입니다.

## 실행 방법

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 기능

- 10개 대국 병렬 실행 (20개 개체를 10쌍으로 매칭)
- 세대 종료마다 상위 개체 엘리트 보존 + 교차/돌연변이
- 속도 제어 (`moves/s`) 및 프레임당 처리량 제어
- 세대 히스토리 누적 및 리플레이 슬라이더
- 실시간 통계 (흑/백/무승부, 평균 적합도)
